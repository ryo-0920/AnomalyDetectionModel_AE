AE Transformer 実行マニュアル
2026/4/15

1. 前提条件の明示

  • 外部サイトからインストールする際の注意
    社内や利用環境で外部サイトからのソフトウェアインストールが許可されているか必ず確認してください。
  • PythonおよびGitのインストール
    Pythonは公式サイトよりダウンロード・インストールしてください。
    Gitは公式サイトからインストール可能です。
  • CUDA対応GPUとドライバ
    CUDA 12.8対応のNVIDIA GPUが必要です。
    ドライバのバージョンは公式CUDAリリースノートで確認してください。
    GPUの有無は「デバイスマネージャー」やコマンドプロンプトで nvidia-smi を実行して確認できます。
  • 環境変数・パス設定の注意
    PythonやGitの実行パスが通っているか確認してください。
    PowerShellやコマンドプロンプトで python --version や git --version を実行し、バージョンが表示されることが目安です。

2. Pythonおよびパッケージのインストール手順

Pythonのインストール

Python公式サイトからWindows用インストーラをダウンロードし、インストールしてください。
インストール時は「Add Python to PATH」を必ずチェックしてください。

pipのバージョン確認とアップデート

python -m pip --version
python -m pip install --upgrade pip

PyTorchのインストール例（CUDA 12.8）

PyTorch公式サイトや社内資料を参照のうえインストールしてください。例：

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128

その他の必要パッケージインストール

pip install numpy pandas matplotlib scikit-learn joblib tqdm

3. 現行フォルダ構造の説明

  • AE/ - 現在のリポジトリルートです。
  • README.html - 本マニュアルです。
  • pages/ - 補足説明用のHTMLファイルとスタイルシートです。
  • 1_transformer/ - 学習・推論・プロットの主な実行スクリプトがある作業ディレクトリです。
  • 1_transformer/models/ - Transformer Autoencoder のモデル定義があります。
  • 1_transformer/artifacts/transformer_ae/ - 学習済みモデル、設定、しきい値、スケーラー、学習曲線を保存します。
  • 1_transformer/result/ - 推論結果CSVと時系列プロット画像の出力先です。
  • datarecode_train/ - 学習用CSVの配置先です。
  • datarecode_test/ - 推論用CSVの配置先です。
  • collect_intentional_accel.py / export_results_excel.py / gofumi_accel_keyboard.py / pngtovideo.py - 必要に応じて使う補助スクリプトです。

4. 学習・推論それぞれの詳細手順

学習

PowerShellを開き、まず 1_transformer/ に移動してから学習を実行してください。

cd 1_transformer
python train_transformer_autoencoder.py

既定では ..\datarecode_train を学習データとして参照します。別のフォルダを使う場合は --csvdir または --csv を指定してください。

python train_transformer_autoencoder.py --csvdir ..\datarecode_train
python train_transformer_autoencoder.py --csv ..\datarecode_train\sample.csv

実行中のログにはエポック数や損失が表示されます。途中で停止した場合はログのエラーメッセージを確認してください。

出力先：1_transformer/artifacts/transformer_ae/

実行時間の目安：環境やデータ量により数十分から数時間かかる場合があります。

推論

学習完了後、同じく 1_transformer/ で推論を実行します。

cd 1_transformer
python train_score_csv.py

既定では ..\datarecode_test を推論対象として参照し、学習済み成果物は artifacts/transformer_ae から読み込みます。

python train_score_csv.py --csv ..\datarecode_test
python train_score_csv.py --csv ..\datarecode_test --artifacts_dir artifacts\transformer_ae

出力先：1_transformer/result/

推論結果のプロット

cd 1_transformer
python plot_timechart.py

既定では result 配下の異常度CSVを読み込み、同じ result/ に時系列プロットPNGを保存します。

python plot_timechart.py --csv result

5. 成果物の説明と活用方法

学習成果物（artifacts/transformer_ae/）

  • model.pt - 学習済みモデルファイル
  • config.json - モデル設定・レイアウト情報
  • threshold.json - 異常検知しきい値情報
  • scaler.pkl - データ正規化用スケーラー
  • loss_curve.png - 学習・検証損失の推移グラフです。

推論成果物（result/）

  • ファイル名_anomaly.csv - 各時刻の異常スコア、誤差、異常判定、異常レベルを含むCSVです。
  • ファイル名_timechart_transformer.png - 推論結果を重ねた時系列プロット画像です。

6. よくあるエラーと対処方法

インストール時の依存関係エラー

Pythonパッケージのバージョン不整合やCUDAの不一致が原因です。
エラーメッセージを参考にバージョンを合わせてください。

実行時のパスエラーやファイル不足

学習・推論・プロットは 1_transformer/ に移動してから実行してください。
別の場所から実行すると、models モジュールや ..\datarecode_train / ..\datarecode_test の相対パスが見つからない場合があります。

GPU利用時のドライバ問題

CUDA対応GPUのドライババージョンが古い場合があります。
nvidia-smi で状態を確認し、必要に応じてドライバ更新してください。

成果物フォルダが見つからない場合

推論時は artifacts/transformer_ae/ に model.pt、config.json、threshold.json、scaler.pkl が必要です。
先に学習を実行し、成果物が保存されていることを確認してください。
